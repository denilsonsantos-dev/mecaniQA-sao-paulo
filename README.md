# mecaniQA-sao-paulo
Projeto acadêmico tendo como intuito o estudo de Modelos de Aprendizado de Máquina. A finalidade deste projeto é desenvolver o módulo fundacional da MecâniQA, que contemplará a modelagem, limpeza e análise de dados históricos de manutenção automotiva, além da implementação de um modelo de previsão baseline para demanda de manutenções preventivas.
